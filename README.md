# AR Placement App for Android

## 📱 Features
- Select a drill from dropdown (Drill 1, 2, 3)
- Tap on ground in AR to place cube/cone
- Plane detection using ARCore
- Simple and lightweight AR demo app

## 🔧 Tech Stack
- Java + Android Studio
- Google ARCore + Sceneform
- Firebase (optional)

## 🚀 How to Run
1. Clone this repo
2. Open in Android Studio
3. Make sure your device supports ARCore
4. Build APK and run on AR-enabled Android phone

## 📌 Notes
- Tested on Android 10+ with AR support
- For unsupported phones, app may crash or show ARCore error
